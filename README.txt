VALTERRA - clon de la web actual de IONOS para GitHub Pages

Esta versión parte del HTML/CSS original guardado desde la web de IONOS.
NO es un rediseño.

CONTENIDO:
- index.html: página original adaptada para GitHub Pages.
- assets/: CSS, imágenes y recursos descargados por Chrome.
- assets/edificio.png: imagen recuperada manualmente.
- assets/transparent.svg: sustituto temporal de la segunda imagen de fondo que IONOS ya no sirve.

PARA SUBIR:
1. Borra el contenido actual de tu carpeta local VALTERRA, salvo la carpeta .git (normalmente está oculta).
2. Copia index.html y la carpeta assets de este ZIP a VALTERRA.
3. GitHub Desktop -> Summary: "Clon web IONOS"
4. Commit to main.
5. Push origin.
6. Espera 30-60 segundos y abre https://jjulen92.github.io/VALTERRA/

IMPORTANTE:
- No tocar todavía Custom domain / DNS.
- El formulario mantiene el aspecto original, pero la lógica de envío de IONOS no funcionará en GitHub Pages.
  Lo conectaremos después, cuando confirmemos primero que la copia visual es correcta.
- La segunda imagen de fondo de IONOS no estaba disponible y queda temporalmente sin imagen.
